# References — persistent inspiration images

Save screenshots and reference images you want to keep, one directory per artwork:

```
references/
  forest-lines/
    reference.png
    reference-2.png
  glass-landscape/
    reference.png
```

Then point Claude at them:

> Use `references/forest-lines/reference.png` and make this in p5.

Saved references are worth it when you expect to come back to a piece later — Claude can re-read
the original intent months from now without you hunting for the image again.

**You do not have to save anything.** Attaching or pasting an image straight into the Claude
Code conversation works just as well for a one-off, and Claude should never refuse to start
because a reference lives in the chat rather than on disk.

Images here are committed to git, so keep them reasonably sized.
